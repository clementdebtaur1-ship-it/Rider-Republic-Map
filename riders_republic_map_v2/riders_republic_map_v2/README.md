# RR Explorer — prototype sérieux

Ce prototype utilise Leaflet 1.9.4 et OpenStreetMap comme fond géographique. Leaflet gère le zoom, le déplacement et les tuiles; les tuiles sont donc chargées au fur et à mesure au lieu de charger une énorme image. Voir la documentation Leaflet.

IMPORTANT :
- Le fond OSM n'est pas la carte graphique de Riders Republic.
- Les points de vue et reliques sont basés sur des guides publics; les positions affichées ici sont une maquette de travail et ne doivent pas être présentées comme des coordonnées exactes du jeu.
- Quelques éléments sont explicitement des exemples.
- Pour une version finale, il faut une image/fond de carte du jeu dont l'utilisation est autorisée, puis calibrer ses coordonnées et saisir les emplacements vérifiés.

Lancer localement :
1. Ouvre le dossier avec VS Code ou un serveur local.
2. Lance un serveur HTTP (par exemple Live Server).
3. Ouvre index.html.
